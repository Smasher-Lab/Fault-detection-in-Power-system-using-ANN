Real-Time Transmission Line Fault Detection & Classification using ANN

Presented by: Lalith (EE24B1030), Prabhat (EE24B1041), Vamsi (EE24B1040)

The Engineering Problem

Transmission lines span vast geographical areas and are constantly vulnerable to severe environmental disturbances like lightning strikes, falling tree limbs, and insulation degradation.

Traditional distance relays rely on static impedance thresholds, which can be deceived by fault resistance, dynamic grid loading, and measurement noise.

Soft Computing Solution

We apply an Artificial Neural Network (Multilayer Perceptron) that directly processes instantaneous 3-phase currents (Ia, Ib, Ic) and voltages (Va, Vb, Vc).

  • Sub-cycle fault classification in under 0.5 milliseconds.
  • Instant trip commands for substation circuit breakers.
  • Integrated real-time telemetry streaming via MongoDB.

Dataset & Preprocessing Pipeline

Electrical Fault Detection and Classification Dataset (7,861 Samples)

Input Features (6)
  • Ia: Phase A current (Amperes)
  • Ib: Phase B current (Amperes)
  • Ic: Phase C current (Amperes)
  • Va: Phase A voltage (p.u.)
  • Vb: Phase B voltage (p.u.)
  • Vc: Phase C voltage (p.u.)
Target Fault Classes
  • No Fault: Balanced continuous load
  • LG (A-G): Single Line-to-Ground
  • LL (B-C): Line-to-Line
  • LLG (A-B-G): Double Line-to-Ground
  • LLL (A-B-C): 3-Phase Symmetrical
  • LLLG (A-B-C-G): 3-Phase with Ground
StandardScaler Scaling

Current magnitudes reach $\pm 1000\text{ A}$ while voltages stay within $\pm 0.6\text{ p.u.}$. Standard scaling is mandatory:

z = (x - μ) / σ

Multilayer Perceptron (MLP) Neural Network

Architecture, Non-Linear Activations & Backpropagation Training

Layer Architecture

  • Input Layer: 6 Neurons (Normalized Ia, Ib, Ic, Va, Vb, Vc).
  • Hidden Layer 1: 32 Neurons with ReLU non-linearity ($a = \max(0, z)$).
  • Hidden Layer 2: 16 Neurons with ReLU for cross-phase correlations.
  • Output Layer: Softmax activation for probability distribution.

Why Soft Computing Excels

Unlike rigid hard-coded relay trip settings, the ANN naturally accommodates fault resistance variations, inception angle differences, and harmonics without recalibration.

Inference Time: ~0.45 ms (Well within 20 ms sub-cycle requirements)

Experimental Results & Symmetrical Fault Discovery

Deep-Dive into Electrical Engineering Physics & Model Accuracy

Baseline 6-Class Model
85.19%

Confuses LLL vs LLLG due to ground current cancellation.

IEEE 5-Class Relay Model
99.55%

Groups 3-phase symmetrical short circuits. Flawless accuracy.

Conductor Localization
99.8%

Phases A, B, C detected with near 100% precision.

The Power Systems Discovery: In a balanced 3-phase fault, $\sum I = I_a + I_b + I_c = 0$, so no ground current flows regardless of ground connection. Categorizing faults according to IEEE protective relay standards achieves 99.55% accuracy.
